# 💻 Carrera de Software

## 📚 Materias Académicas

Este repositorio contiene las actividades, prácticas, ejercicios, investigaciones y proyectos desarrollados durante mi formación en la carrera de Software.

El objetivo es organizar y documentar los conocimientos adquiridos en las diferentes asignaturas.

---

## 🌐 1. Redes de Computadoras

### Descripción
Esta asignatura permite comprender cómo se comunican los dispositivos dentro de una red, los protocolos de comunicación y la infraestructura necesaria para transmitir información.

### Temas principales
- Conceptos básicos de redes.
- Modelos OSI y TCP/IP.
- Direccionamiento IPv4 e IPv6.
- Máscaras de subred.
- Protocolos de comunicación.
- Configuración de redes LAN y WAN.
- Dispositivos de red (routers, switches y hubs).
- Seguridad informática y redes.

### Actividades y prácticas
- Prácticas de configuración de redes.
- Ejercicios de direccionamiento IP.
- Investigaciones sobre protocolos.
- Simulaciones de redes.
- Documentación de trabajos realizados.

---

## 🖥️ 2. Arquitectura de Computadoras

### Descripción
Esta asignatura estudia la estructura y el funcionamiento interno de los computadores, sus componentes físicos y la manera en que interactúan para ejecutar instrucciones y procesar información.

### Temas principales
- Introducción a la arquitectura de computadoras.
- Componentes de un computador.
- Unidad Central de Procesamiento (CPU).
- Unidad de Control y ALU.
- Memoria RAM y ROM.
- Jerarquía de memoria.
- Sistemas de entrada y salida.
- Sistemas de numeración binario, decimal y hexadecimal.
- Lenguaje máquina y lenguaje ensamblador.
- Ciclo de búsqueda, decodificación y ejecución.

### Actividades y prácticas
- Investigaciones sobre componentes del computador.
- Ejercicios de conversión de sistemas numéricos.
- Análisis del funcionamiento del procesador.
- Prácticas sobre memoria y almacenamiento.
- Desarrollo de ejercicios de arquitectura computacional.
